⌨️ New exercise: Type the translation — what's new

Lessons now include typed production: you read the English and TYPE the sentence in your target language from memory. It's the toughest, highest-retention drill — great for getting to fluency, and it builds spelling too.

Grading is forgiving: it ignores capitalization, spacing, and accents, and tolerates a small typo, so a missing umlaut won't fail you — but it still pushes you to recall the real word.

WHAT TO TEST
• Play a few review lessons until a "Type this in the target language" screen appears; type the answer and Check.
• Try it with a missing accent (e.g. type "uber" for "über") — it should still accept it.
• Type something clearly wrong — it should mark it and show the correct answer.
